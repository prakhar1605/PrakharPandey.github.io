Research

Navigating Epistemic Parity in LLM Agents: A Benchmark for Cross-Source Conflict Resolution Between Memory and Procedural Skills

Prakhar Pandey, sole author
NeurIPS 2026 workshop “Who Verifies the Agents?”, December 2026

When an agent's memory and its SKILL.md instructions disagree, which one wins? I built a 52-scenario benchmark and ran 1,383 deterministically graded runs across three open-weight models. Neither source reliably wins, agents resolved the conflict without telling the user in 98.8% of tool-call runs, and one generic “skill takes precedence” line took a model from 28% to 90% on performing forbidden irreversible actions.
